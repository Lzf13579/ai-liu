# 安装说明 —— dsh-approval-enter

让 DSH Web 的审批弹窗可以用**回车**确认「允许一次」。

> 下文用 `<插件目录>` 表示你解压/克隆出来的 `dsh-approval-enter` 目录的绝对路径，
> 例如 `D:\dsh-plugins\dsh-approval-enter`。请按自己的实际位置替换。

---

## 一、安装（本地目录，推荐）

```powershell
dsh plugin --profile web add link:<插件目录>
```

装完**必须重启 DSH Web**：前端模块的 rev 在后端启动时才分配，只改文件不重启，浏览器可能继续用缓存里的旧模块。

重启后第一次加载建议 **Ctrl+F5** 强刷。

---

## 二、验证装上了

浏览器控制台：

```js
window.__dshApprovalEnter
// { installed: true, version: "0.1.0", triggers: 0, find: f }
```

- 打印出对象 → 脚本已注入 ✅
- `undefined` → 脚本没加载，检查下面「排查」

然后触发一次审批（让 Agent 跑一条需要授权的命令），**按回车**：

- 弹窗立刻按「允许一次」结算 ✅
- `window.__dshApprovalEnter.triggers` 变成 `1`

---

## 三、手工安装（不用 dsh plugin 命令）

1. 把整个 `dsh-approval-enter` 目录放到一个固定位置。
2. 编辑 profile 的 `package.json`（默认在 `%USERPROFILE%\.dsh\profiles\web\package.json`），在 `dependencies` 里加：

   ```json
   "dsh-approval-enter": "link:<插件目录>"
   ```

3. 在 `dsh.profile.bundles` 数组里加上插件名（没有这个数组就新建）：

   ```json
   "dsh.profile.bundles": ["dsh-approval-enter", "...原有的项..."]
   ```

4. 重启 DSH Web。

> ⚠️ 两个 `package.json` 相关的坑：
> - 文件必须是 **UTF-8 无 BOM**。PowerShell 的 `Set-Content -Encoding utf8` 会写 BOM，DSH 读到会解析失败 —— 用记事本/VS Code 另存为「UTF-8（无 BOM）」，或用 `[System.IO.File]::WriteAllText(path, text, (New-Object System.Text.UTF8Encoding($false)))`。
> - `dsh.profile.bundles` 里缺了插件名，即使依赖装上了也不会被加载。

---

## 四、排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `window.__dshApprovalEnter` 是 `undefined` | 脚本没注入 | 确认 `dsh.profile.bundles` 里有 `dsh-approval-enter`；确认重启过 |
| 脚本注入了，但回车没反应 | 拿到的 `index.html` 里没有 `</body>` | 本插件会退化到追加到末尾，一般不会失败；换个 DSH 版本再试 |
| 回车把草稿发出去了 | 有另一个更早注册的捕获监听抢走了事件 | 见下面「与补丁 3 冲突」 |
| 回车变成了「拒绝」 | 不可能 —— 插件绝不会点「拒绝」。若真发生，请开 issue | — |

### 与「补丁 3」冲突（重要）

如果你之前打过 bundle 内补丁 3（往 `@deepseek-ai/dsh-client-ui-approval` 的 `lib\client.js` 里插「回车 = 允许一次」那段 hook），**它和本插件会同时响应回车**，导致 `answer()` 被调用两次，第二次因为「已经答过」而抛错（页面上看着正常，控制台有报错）。

装了本插件后请把补丁 3 撤掉，把该文件从同目录的 `client.js.bak-enter` 还原：

```powershell
$ui = "$env:LOCALAPPDATA\Programs\DeepSeek\runtime\bundle\node_modules\@deepseek-ai\dsh-client-ui-approval\lib"
Copy-Item "$ui\client.js.bak-enter" "$ui\client.js" -Force
```

然后重启 DSH Web。

---

## 五、卸载

```powershell
dsh plugin --profile web remove dsh-approval-enter
```

插件不写任何文件、不改任何配置，删掉目录即彻底干净。

---

## 六、行为细节

| 按键 | 行为 |
| --- | --- |
| `回车` | 有审批弹窗 → 点「允许一次」；没有弹窗 → 完全放行，不影响输入框 |
| `Shift+回车` | 放行（换行） |
| `Ctrl` / `Alt` / `Win` + `回车` | 放行（组合键） |
| 长按回车（`event.repeat`） | 忽略，不连发 |
| 中文输入法组字中 | 忽略，不误触发 |
| 弹窗按钮已 `disabled`（已答过） | 忽略 |
| 弹窗不可见 | 忽略 |
