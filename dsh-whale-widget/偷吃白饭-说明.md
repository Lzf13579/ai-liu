小鲸鱼余额挂件 · 插件说明

- 作者 / 昵称：三萌MOE
- 基于官方版本：v0.3.0
- 衍生版号 / 日期：v0.3.6-mod / 2026-09-19
- 一句话功能：这个是在安装了小鲸鱼余额插件之后再安装的额外插件，会让你的大肥鱼在每次对话后根据消耗的金额偷吃白饭

【改了什么】
1.让你的小鲸鱼余额插件可以在每次对话后根据消耗的金额做出不同阶段的偷吃白饭功能（一口，两口，三口）
2.她碗里的饭**忙时和闲时不一样**：忙时（那个时段一口吃掉的钱更多）碗里更丰盛，闲时更素净。
   这个"现在是不是忙时"是**直接问小鲸鱼插件自己**的（它的余额气泡本来就知道），
   所以它哪天改了折扣日历（比如后来改成周末整天空闲），这里自动跟着变 —— **不用更新本插件**。
3.点击小鲸鱼出现气泡后，小鲸鱼右上角会出现偷吃白饭菜单，里面可以设置小鲸鱼偷吃白饭后嘴上残留的米粒图，并且调整位置，以及根据小鲸鱼余额挂件0.3.0新功能中添加的不同角色保存成不同的米粒位置图（默认用随包自带的那张米粒图，也可以点「选择图片…」换成你自己的，见下）
4.她吃的时候会有音效，**每吃一口响一声**；音量在面板里调，也可以整个关掉（见下）
5.可以让她**随机偷吃**（不再每轮都吃），也可以在她吃的时候**点她抓现行**（见下）
6.菜单里有个「唱歌」按钮，点一下她会唱歌（群里这个版本自带一首），再点一下停；
   换歌只要把音频文件丢进 songs 文件夹（见下）
7.可以让她**开工时自己唱一首**：你在 DSH 里开始干活她就唱，**最少隔几分钟**由你决定；
   她一开始吃饭那首就停 —— **想听完就点一下按钮上的「留住」**，那下不会打断它（见下）
8.这个是插件，需要在DSH安装小鲸鱼余额插件0.3.0版本后，再安装该插件才有效果，只安装本插件并不会让你拥有小鲸鱼余额插件

【随机偷吃】
面板「开关」里有一行「随机偷吃」，勾上之后她**不再每轮都扒一口**，而是：

- 每次结算一轮，掷一次骰子
- **掷中了才吃**，而且把之前攒着的一次吃完（所以那一顿口数更多）
- **没掷中就一口不吃，攒着**，等下次掷中

下面那条「概率」滑杆就是掷中的机会（0~100，默认 50）。
**关掉随机偷吃之后那条滑杆会自己藏起来** —— 不开随机的时候它没意义。

顺带说一句：打开随机之后，**别的应用 / 别的设备花掉的钱也一起攒着**
（不然它会绕过骰子，把刚攒下的那份顺手吃掉，就攒不住了）。

【抓到她偷吃】
**她饭碗还举着的时候点她 = 抓现行。** 点下去会看到四拍：

1. 碗里的饭**一下子没了**
2. 碗**弹起来**
3. 在空中翻过去，**转满 180 度**
4. **倒扣在旁边**停住 —— 过一会儿，**和脸上的米粒一起消失**

- 不需要按什么特别的按钮，就是**平常点她**那一下
- 只在她**正吃着**的时候才算数；碗已经放下去了，点她就还是小鲸鱼原来的反应
- 右键不算

**想自己看效果**：点面板里的「试吃」让碗举起来，趁碗还没放下的时候点她。

【菜单长什么样】
菜单是**分组的**，点每一组的标题就能展开/收起，不用在一长条里上下找：

  开关
  位置微调（方向键也行）
  素材 · 米粒与碗
  音效
  唱歌

最下面那一行**一直在**：

  [♪ 唱歌]  [试吃]  [保存]  [重置]

不管哪一组开着、也不管菜单滚到哪儿，它们都够得着。

菜单**不会压在小鲸鱼身上**，也不会被挤出屏幕。

这条不是"顺手做的"：小鲸鱼的**拖动**、**点一下弹余额**，都只在**按到她身上**时才触发
（她内部有一张逐像素的命中图），她自己的 ☰ 菜单按钮也在她身上的右上角。
菜单要是压上去，这三件事就一起被挡住了 —— 那就变成"点菜单"和"摸她"打架。

所以菜单的规矩是：**首选放在她整个方块的上方**（那块地既没有她、也没有余额气泡，
是最干净的位置）；只有那块地真的矮到没法用时（鲸鱼放到最大、屏幕又矮），才退到她旁边或下方；
**哪边都不够时，宁可菜单变矮、在里面滚动，也不压过去**。
收起和展开**不会换位置** —— 展开只是往上长。
—— 所以把鲸鱼放大到很大、或者屏幕很矮，菜单都还在，而且不会挡住她。

【怎么让她唱歌】
点最下面那个「♪ 唱歌」按钮就行：**点一下开始唱，按钮会陷下去，她跟着轻轻晃；
再点一下停。**

那个按钮上的字**会跟着状态变**，因为"点它会怎样"会变：

  「唱歌」  还没在唱        →  点一下：开始唱一首
  「留住」  **自动**在唱      →  点一下：**接管**（不打断、不重来，之后再点才是停）
  「停止」  手动在唱        →  点一下：停

为什么要多一个「留住」：她开工时自动唱的那首是**你没要求、她顺手唱的**，
所以那一下不该把你正在听的东西掐掉 —— 想听完就点一下「留住」，她会唱完，
连她开始吃饭都不会停；不想听就点两下（第一下留住、第二下停），
**中间声音一秒都没断**。

**想换歌 / 加歌**：把音频文件丢进**插件目录下的 songs 文件夹**（和 art 文件夹并排）：

  dsh-rice-widget\
    art\        ← 插件用的图
    songs\      ← 歌丢这里
      let-me-go.webm    ← 群里这个版本自带的那首
    lib\
    package.json

- **不用改歌名** —— 文件名就是面板上显示的歌名
- **不用重启、也不用刷新页面** —— 每次点「唱歌」都会重新看一遍那个文件夹
- **一首就唱那一首；多首就随机唱一首**（而且不会连着唱同一首）
- 文件夹不存在的话，插件会自己把它建出来
- **音量跟着小鲸鱼挂件自己的音量走** —— 把挂件声音调小，她唱歌也一起变小
- 如果你在小鲸鱼挂件里把音效整个关掉了，这里也不会响（面板上会写明原因）

**能放什么格式**：扩展名得是下面这些之一，否则那个文件**根本不会出现在歌单里**。

  mp3    到处都能放                ← 最保险
  m4a    到处都能放（mp4 也行）     ← 最保险
  wav    到处都能放，但文件很大
  flac   现代浏览器都行（无损）
  ogg    谷歌/火狐行，苹果浏览器不行
  oga    同上
  opus   同上
  weba   同上（webm 也行）
  aac    不一定，要给别人听就转成 m4a

**给一群人听就选 mp3 或 m4a** —— 这两个不用赌对方用什么浏览器。
你自己在 Chrome / Edge 上用的话，上面全部都能放。

另外几条：
- 扩展名不分大小写（.MP3 一样认）
- **只认 songs 文件夹这一层**，在里面再建子文件夹是不管的
- 隐藏文件（名字以点开头）和 0 字节的空文件会被跳过
- 歌有多大都行（几十 MB 的无损也能放），但**一首 2~10MB 最舒服**

**没有进度条是有意的**：那会让一个逗她玩的按钮变成一个播放器，
而这里真正需要的只有两件事 —— 开始、停。

**唱歌和试吃撞上会怎样**：**两个都能用，谁也不取消谁。**
- 她正在唱歌的时候点「试吃」→ **歌不会停**，只是那几下里**歌会自己小声一点**，
  让"吃饭"的声音听得出来；吃完歌自己恢复原样。
- 她正在吃的时候点「唱歌」→ 歌照放，那顿饭也不打断。
- 她会**一边上下晃、一边把那一口吃掉** —— 晃动和咀嚼是分开做的，两个都看得见，
  嘴角那几粒米也会跟着她一起晃。

【让她开工时自己唱一首】
面板「唱歌」那一组里有个「**开工时唱一首**」（默认是开着的）。
打开之后**你在 DSH 里开始干活，她自己唱一首**，不用去点按钮；
下面那条「**最少隔**」滑杆决定两次之间至少隔多少分钟（默认 5 分钟，填 0 = 每一轮都唱）。
连着发几条消息只会唱一次，中间隔够了才会再唱。

**她一开始吃饭，这首歌就停。** 自动唱配的是"你还在思考"那段时间；
你这边出了结果、她张嘴吃饭，那首歌的用处就结束了，再唱下去只会和吃饭那几声打架。
（**自己点的那首不停** —— 那是你要听的，只压小、不掐断，见上面。）

**想听完就在她开吃之前点一下「留住」** —— 那一下不会打断它，只是让它变成
"你自己要听的那首"，于是她开吃也不停，你能听完整首。

几条"看起来像坏了、其实是有意"的：

- **不发消息就不会唱** —— 触发点是"DSH 开始处理一轮"，不是定时器
- **同时开好几个对话不会打架**：那些对话都在**同一个页面**里（切换不改网址、不重载），
  所以她只有一个播放器，正唱着的时候别的对话开工只会被记下来、不会插进来。
  她**不知道你在哪个对话里** —— 歌跟着"DSH 在干活"走。
  但**别开两个浏览器窗口**：那会同时唱两首（各自随机），想安静就在任一窗口把
  「开工时唱一首」取消勾选并保存（那是全局设置）
- **最多晚几秒才开口**：那个信号是搭页面本来就有的轮询捎回来的（不额外发请求），
  所以最坏情况要等一个轮询周期（默认 3 秒）
- **刷新页面不会突然唱**：只认够新的那次开工（默认 20 秒以内），更旧的当历史
- **浏览器窗口在后台时不唱**，切回前台也不会补唱
- **如果你从头到尾没点过这个页面**，浏览器不许它出声 —— 这是浏览器的规矩，
  这种情况只在控制台留一句话，不会弹提示打扰你（自己点按钮时另说，那时会告诉你原因）

【影响范围】
- 影响的功能：让你的小鲸鱼立绘可以偷吃白饭
- 不影响的功能：小鲸鱼余额插件的其他功能都不会被影响——但是她会经常偷吃，你可能会觉得有点烦
- 已知问题：未添加图片的SVG会在小鲸鱼余额插件的图片缩放到最小的时候依旧显示得很大——别担心，这是变小的小鲸鱼在偷吃大米

【安装与回滚】
- 安装：dsh plugin --profile web add link:<解压后的目录> → 重启 dsh web → 浏览器 Ctrl+F5
- 回滚：dsh plugin --profile web remove dsh-rice-widget → 重启 dsh web → 浏览器 Ctrl+F5

【怎么换成自己的米粒图 / 碗 / 饭的图】
默认用的都是插件自带的那几张，不用管。想换成自己的：

1. 点小鲸鱼右上角那个「偷吃白饭」标签，打开面板
2. 展开「**素材 · 米粒与碗**」那一组
3. 想换哪个就点那一行的「**选择…**」，选一张你电脑/手机里的图

   米粒图 —— 吃完留在嘴上的那几粒米
   碗     —— 空碗（只有碗、没有饭）
   波峰饭 —— 忙时段的饭（那个时段一口吃掉的钱更多，碗里就该更丰盛）
   波谷饭 —— 闲时段的饭
   用哪一碗饭是随小鲸鱼自己的时段判断自动切的，不用你管

   - **不需要填任何路径，也不需要把图片放到某个文件夹里**
   - 选中的图会被存进配置里，**每个角色可以各用一套**
4. 位置和大小可能要对一下 —— 用面板上的九宫格和「大小」调，看着顺眼就行
5. 点「**保存**」

想换回自带那张，点旁边的「**默认**」按钮。

**碗和饭的图要成对**：两张都是 196×196、预先对齐好的，叠起来才是一碗饭。
所以换的时候最好两张一起换成你自己对齐过的一套。
图删了、丢了、路径错了都不会报错 —— 它会自动退回内置画出来的那个碗和那簇白米粒。

【怎么调音量 / 换音效】
她每吃一口会响一声。默认是开的，位置和音量都能改：

1. 打开面板（点小鲸鱼右上角那个「偷吃白饭」标签）
2. **音量**在「音效」那一组的「音量」那一行，**刻度 0 到 10，默认 5**
   - 觉得吵就往左拉；**拉到 0 就不响**
3. **想整个关掉**：取消「开关」那一组里「**音效开关**」的勾选
4. **想换成自己的音频**：「吃饭音效」那一行点「**选择音频…**」，选一个音频文件
   - 和图片一样，**不需要填路径，也不用把文件放到任何目录**
   - 选完会**立刻试听一声**；拖完音量滑杆松手也会试听一声
   - 点旁边的「**默认**」可以换回插件自带那个
5. 改完点「**保存**」

**注意**：如果你在鲸鱼插件那边把音效整个关掉了，这里也不会响 ——
那是总开关，这边只是它下面的一层。

【音效没响？】
点页脚那个「**试吃**」，它会当场告诉你为什么 —— 开关关了？音量是 0？
文件取不到？还是鲸鱼那边静音了？四个原因，以前一个提示都没有。

【网络请求】
本插件**不发起任何外部网络请求**，所有数据都在本机。

宿主侧（Node）：
- 不访问互联网，也不调用任何模型接口。只读写本机的两个文件：
  ~/.dsh/.dsh-rice-config.json（面板设置）、~/.dsh/.dsh-rice-state.json（账目状态）
- 另外会**读**（不写）插件目录下的 songs 文件夹，只是为了列出里面有哪些歌
- 订阅 DSH 自己的会话事件流（`session/event`），但**只看一件事**：这一轮是不是刚开始
  （用来触发"开工时自动唱一首"）。**不读对话内容、不读工具调用、不外发任何东西** ——
  它拿到的只有 `turn/start` 这个事件名，以及一个"现在几点"的时间戳
- 注册 15 条本机路由供页面调用（只绑定 127.0.0.1，仅本机可访问）：
  GET  /dsh-rice/rice.js           前端脚本本体
  GET  /dsh-rice/config            读取开关与参数
  POST /dsh-rice/config            保存开关与参数
  POST /dsh-rice/observe           页面把观测数据送回来，取回「该吃几口」
                                   （「最近一次开工是什么时候」也搭这一趟车回来，不额外发请求）
  POST /dsh-rice/feed              按需触发一次试吃（录演示用）
  GET  /dsh-rice/songs.json        歌单（songs 文件夹里有哪些歌）
  GET  /dsh-rice/song?f=<文件名>    放歌
  GET  /dsh-rice/rice.png          米粒图
  GET  /dsh-rice/bowl.png          碗（只有碗那张）
  GET  /dsh-rice/food-peak.png     忙时段的饭
  GET  /dsh-rice/food-valley.png   闲时段的饭
  GET  /dsh-rice/nang.weba         吃饭音效
  GET  /dsh-rice/arrow-tick.weba   音效素材
  GET  /dsh-rice/song.png          唱歌按钮的图标
  GET  /dsh-rice/egg-1.png         图片素材
  GET  /dsh-rice/egg-2.png         图片素材
  说明：art/ 和 songs/ 目录下的文件，**都只是被读出来发给页面**，不解析、不上传。
  你自己在面板里选的图和音频**不会经过这些路由** —— 它们是直接存进本机配置里的一段数据。
  **放歌那条路由只认歌单里已有的文件名**，不接受任何路径 ——
  所以 /dsh-rice/song?f=../../../某个文件 这种写法读不走你机器上的任何东西（实测一律 404）。

前端侧（浏览器）：
- 只请求同一个来源的地址：/dsh-rice/* ，以及鲸鱼挂件自己的
  /dsh-whale/last-turn.json、/dsh-whale/balance.json、/dsh-whale/size.json
- localStorage 只读一个键：dshw-role（那是鲸鱼挂件自己写的当前角色），不写任何东西

**发送内容：只有金额数字、轮询序号、以及当前角色 id。不发对话内容、不发 token、不发任何凭据。**

【上传前自检（全部打勾才能传）】
☑ 已清理本机隐私：绝对路径 / 用户名 / 内网 IP / 个人域名，全部没有
☑ 已排除运行时数据：.credentials.yaml、.env、.dshw-*.json、whale-*、sessions、node_modules
☑ 已排除我个人的图库/音效 id（bimg_xxx / audio_xxx）与个人截图、余额数字
☑ 无任何硬编码密钥；代码里只出现「凭据名」（如 DEEPSEEK_API_KEY）
☑ 已列出全部网络请求：地址 + 用途 + 发送内容（见上面【网络请求】一节）
☑ node --check 宿主与前端两个文件都通过
☑ 宿主路由已接入 DSH 信任栅栏（`connection.requestRejection`，和鲸鱼 0.3.3 起同一套）
   **15 条路由全部走同一个注册入口**，不靠"记得加"——漏一条的表现是接口静默敞着，看不出来
   实测：栅栏放行时正常服务；栅栏返回 401 / 403 时逐条扫 15 条，**全部被拦且 handler 不执行**；
   栅栏不可用时放行（fail-open）并只 warn 一次 —— 宁可少一层防护，也不让插件整个不工作
   为什么必须有它：跨站的 `Content-Type: text/plain` POST 属于"简单请求"、**不触发预检**，
