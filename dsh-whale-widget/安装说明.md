# 小鲸鱼挂件 · 合并版 安装说明（v0.3.8-rice）

**这是什么**：DeepSeek Harness（DSH）Web 界面右下角的**余额小鲸鱼挂件**，并已把
「**偷吃白饭**」与「**Token 用量方框**」合并进本体 —— **只需要装这一个插件**。

| 组成 | 来源 | 许可 |
|---|---|---|
| 鲸鱼挂件本体（余额 / 气泡 / 角色 / 音效 / 吸附翻转…） | [MeteorNOX/DeepSeek-Balance-Whale-Widget](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget) | MIT |
| 「偷吃白饭」（原 `dsh-rice-widget`） | **三萌MOE**（0.3.6-mod） | MIT |
| 「Token 用量」方框 | 本地增强 | MIT |

---

## 一、前置条件

- 已安装 **DSH 桌面端**，并且有 `web` profile（正常安装就有）
- 能用 `dsh` 命令（桌面端自带）

> **不需要**另外安装原版 `dsh-whale-widget`，也不要同时装 —— 本包已经把它包含在内。
> 如果你**以前装过**原版挂件，先移除（见第四节）。

---

## 二、安装（推荐：解压 + link）

1. 把压缩包解压到**一个你不会随手删掉的目录**，例如：

   ```
   D:\dsh-whale-widget-0.3.8-rice
   ```

   > ⚠️ `link:` 安装是指向这个目录的软链 —— **以后别移动或删除它**，否则插件会失效。

2. 打开 PowerShell，执行：

   ```powershell
   dsh plugin --profile web add link:<上面那个目录的绝对路径>
   ```

   例如：

   ```powershell
   dsh plugin --profile web add link:D:\dsh-whale-widget-0.3.8-rice
   ```

3. **完整重启 DSH 桌面端**（关闭并重新打开）。

   > host 侧新增了路由，**只刷新页面不生效**；必须重启。

4. 重启后在浏览器里 **Ctrl+F5 强刷一次**。

---

## 三、装好后你应该看到

- 右下角出现小鲸鱼挂件；点她身上的 **☰** 打开菜单
- 菜单里「**每轮消耗提示**」那一行的**正下方**多出一条 **🍚 偷吃白饭**（与「导入」按钮同款、左对齐）
- 再下一行是 **Token 用量** 开关
- 点「🍚 偷吃白饭」会展开一个独立面板（开关 / 位置微调 / 素材 / 音效 / 唱歌 五组）
- 角色（她本体）右上角还有一个 **🍚 偷吃白饭** 角标，点它也能开同一个面板

**它怎么工作**：每结算一轮对话，按这一轮的消耗金额决定她扒几口白饭；忙时/闲时碗里的饭不一样；
攒着的量在「随机偷吃」模式下会累积到下次一起吃。面板里可以调口数阈值、概率、音量、换米粒图/碗/饭/音效、放歌。

---

## 四、如果你以前装过原版挂件

先移除，再按第二节安装：

```powershell
dsh plugin --profile web remove dsh-whale-widget
dsh plugin --profile web add link:<本包解压目录>
```

---

## 五、卸载 / 回滚

```powershell
dsh plugin --profile web remove dsh-whale-widget
```

然后**完整重启 DSH**。如果删除后想恢复官方版：

```powershell
dsh plugin --profile web add dsh-whale-widget
```

## 七、常见问题

**菜单里找不到「🍚 偷吃白饭」？**
① 有没有**完整重启**桌面端（不是只刷新）？② 浏览器有没有 **Ctrl+F5**？
③ 确认插件确实加载了（`dsh plugin --profile web list` 之类）。

**面板能开，但碗是个简单的图形、吃东西没声音？**
你拿到的是**精简版** —— 见第六节。这是预期的降级，不是坏了。

**面板上的设置保存了，刷新后不见了？**
检查 `~/.dsh/` 下有没有 `.dshw-rice-config.json`；没有写入权限时保存会静默失败。

**她为什么不吃？**
默认开了「随机偷吃」（概率 50%）——没掷中就**攒着**，下次掷中一起吃。
面板「开关」里关掉「随机偷吃」就会每轮都吃。

## 八、网络与隐私

- 本插件**不发起任何外部网络请求**，只与本机 DSH 后端通信
- 面板里你自己选的图片/音频以 data URI 形式存在**本机配置**里，不上传
- 所有自定义路由都走 DSH 的信任栅栏（跨站请求会被拒）；放歌那条路由**只认歌单里的文件名**，不接受路径
